# Monitoring des Affiliations et Corrections dans OpenAlex (MACO) 

Ce dépôt Github contient les deux premières versions de l'application interne à Sorbonne Université pour suivre les demandes de corrections envoyées à [OpenAlex](https://openalex.org/) 
via l'outil développé par le ministère de l'enseignement supérieur et de la recherche : [works magnet](https://works-magnet.esr.gouv.fr/).
